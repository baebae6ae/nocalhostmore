# 🚀 Nocalhostmore

**더 이상 로컬호스트는 그만 — 바이브 코더를 위한 프로덕션 레벨 아키텍처 프롬프트 제너레이터**

> "기능은 AI가 짜고, 뼈대는 시스템이 잡는다."

기능 구현에만 매몰되어 몇 번이고 폐기했던 코드의 근본 원인은 대부분 **처음 설계**에 있습니다.
Nocalhostmore는 코딩을 시작하기 **전에**, 소프트웨어 공학의 정석을 초보자의 일상 언어로 물어보고,
그 답을 **AI가 절대 빠져나갈 수 없는 프로덕션 제약 프롬프트**로 번역해 주는 크롬 확장프로그램입니다.

---

## ✨ 무엇을 하나요?

1. **이륙 전 체크리스트** — "누가 쓰나요?", "파일을 올리나요?", "비밀 키가 들어가나요?" 같은
   쉬운 질문을 한 화면에 하나씩 던집니다. 모르면 **"잘 모르겠어요"**를 눌러 이유와 함께 추천을 받습니다.
2. **가드레일 프롬프트 생성** — 답변을 상태 관리 / 멀티 테넌시 / 파일 I/O / 비밀 관리 / 아키텍처
   규칙으로 매핑해, Cursor·Claude·ChatGPT에 **가장 먼저** 붙여넣을 마스터 프롬프트를 만들어 줍니다.
3. **복사 한 번** — 완성된 프롬프트를 클립보드로 복사해 바로 사용합니다.

이 프롬프트는 단순 요구사항 명세서가 아니라, LLM의 페르소나에 소프트웨어 공학 매뉴얼을 주입하는
**'제약의 감옥(Constraint Prison)'** 입니다.

---

## 🧩 설치 방법 (개발자 모드)

1. 이 저장소를 내려받습니다. (`git clone`)
2. 크롬 주소창에 `chrome://extensions` 입력 → 우측 상단 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** 클릭 → 이 폴더 선택
4. 툴바의 🚀 아이콘을 누르면 체크리스트가 열립니다.

> 아이콘을 다시 만들고 싶다면: `npm run icons`

---

## 🗺️ 질문 → 아키텍처 규칙 매핑

체크리스트의 각 선택지는 백엔드에서 아래 규칙으로 번역됩니다. (`js/promptBuilder.js`)

| 질문 | 선택 | 주입되는 프로덕션 규칙 |
|---|---|---|
| **누가 쓰나요** | 나 혼자 | 전역 변수 허용, 세션 분리 생략 |
| | 여러 명 · 격리 | `st.session_state`(Py) / 요청별 세션(JS) 강제, 전역 변수에 사용자 데이터 저장 금지 |
| | 여러 명 · 공유 | DB/캐시(Redis)로 상태 동기화, 경쟁 상태 방지(락/트랜잭션) |
| **파일 업로드** | 일회성 | UUID 파일명, `try/finally`에서 임시파일 강제 삭제, 확장자·크기 검증 |
| | 영구 보관 | S3 등 오브젝트 스토리지, 사용자 ID 폴더 격리, path traversal 차단 |
| **기록 저장** | 임시 | 인메모리 + "재시작 시 소실" 명시 |
| | 영구 | ORM(SQLAlchemy / Prisma) 강제, raw SQL 금지, 개발/운영 DB 분리 |
| **비밀 키** | Streamlit | `st.secrets` 만 사용, 하드코딩 금지 |
| | 일반 클라우드 | `.env` + dotenv, `.gitignore`에 `.env` 추가, `.env.example` 제공 |
| **로그인** | 있음 | 비밀번호 해싱(bcrypt), 세션/JWT 인증, 평문 저장 금지 |
| **UI 포함** | 예 | Streamlit / Next.js 풀스택 뼈대 |
| | 아니오(API) | FastAPI / Express 강제, CORS 세팅, 라우터·모델·서비스 폴더 분리 |

여기에 공통 안티패턴 금지(빈 예외 처리, 입력 미검증 등)와, 아이디어에 AI가 언급되면
**외부 API 비용 보호**(타임아웃·재시도·호출 상한) 규칙이 자동으로 추가됩니다.

## 📁 프로젝트 구조

```
nocalhostmore/
├── manifest.json          # 크롬 확장 매니페스트 (MV3)
├── popup.html             # 팝업 진입점
├── styles.css             # 팝업 스타일
├── js/
│   ├── questions.js       # 체크리스트 질문 + 분기(라우팅) 데이터 모델
│   ├── promptBuilder.js   # 답변 → 가드레일 마스터 프롬프트 조립 엔진
│   └── app.js             # 위저드 컨트롤러(렌더링·진행·복사)
├── icons/                 # 생성된 PNG 아이콘 (16/32/48/128)
└── scripts/
    ├── gen-icons.cjs      # 무의존성 PNG 아이콘 생성기
    └── test.mjs           # 순수 로직 스모크 테스트
```

---

## 🛠️ 개발

```bash
npm run icons   # 아이콘 재생성
npm test        # 질문 그래프 무결성 + 프롬프트 생성 검증 (48개 케이스)
```

`questions.js`(질문/분기)와 `promptBuilder.js`(문장 조립)는 DOM 의존성이 없어
`npm test`로 단독 검증됩니다. UI 로직은 `app.js`에 격리돼 있습니다.
