# Nocalhostmore

**더 이상 로컬호스트는 그만 — 바이브 코더를 위한 프로덕션 레벨 아키텍처 프롬프트 제너레이터**

> "기능은 AI가 짜고, 뼈대는 시스템이 잡는다."

기능 구현에만 매몰되어 몇 번이고 폐기했던 코드의 근본 원인은 대부분 **처음 설계**에 있습니다.
Nocalhostmore는 코딩을 시작하기 **전에**, 소프트웨어 공학의 정석을 초보자의 일상 언어로 물어보고,
그 답을 **AI가 절대 빠져나갈 수 없는 프로덕션 제약 프롬프트**로 번역해 줍니다.

**두 가지 형태로 제공됩니다 — 핵심 로직은 완전히 공유합니다.**

| | 웹사이트 (주력) | 크롬 확장 (보조) |
|---|---|---|
| 대상 | 챗봇·에이전트 사용자 모두 | 챗봇 사용자 |
| 진입 | `index.html` (랜딩) → `app.html` (생성기) | 툴바 아이콘 → `popup.html` |
| 추가 기능 | 가이드(SEO), 히스토리, **스타터 레포 zip(Pro)**, 광고 | 없음(가볍게) |
| 배포 | 정적 호스팅(Vercel·Netlify·GitHub Pages, 무료) | Chrome Web Store |

> **왜 웹사이트가 주력인가?** 에이전트형 사용자(Cursor·Claude Code)는 브라우저가 아니라 IDE에 삽니다.
> 확장은 그들에게 닿지 않지만, 사이트는 복사→붙여넣기로 두 부류를 모두 커버합니다.
> `questions.js`·`promptBuilder.js`(순수 로직)를 둘이 그대로 공유하므로 유지비는 사실상 하나입니다.

## 디자인 방향

전형적인 "보라-파랑 그라디언트 + 다크 디폴트 + 이모지 배지" SaaS 템플릿을 피하고,
기술 매뉴얼/터미널에 가까운 편집 스타일을 씁니다.

- **색**: 그라디언트 없음. 따뜻한 종이색(라이트) / 잉크색(다크, `prefers-color-scheme` 자동 전환) 배경에
  테라코타 액센트 하나만 절제해서 사용합니다.
- **타이포**: 헤딩은 세리프(`--font-serif`), 본문은 시스템 산세리프, 코드·라벨·브랜드 워드마크는
  모노스페이스(`--font-mono`) — 외부 폰트 로딩 없이 시스템 폰트 스택만 사용합니다.
- **아이콘**: 그라디언트 화살표 대신 터미널 프롬프트(`>_`) 글리프. `scripts/gen-icons.cjs`에서 생성합니다.
- **카피**: 이모지·과장된 감탄사·문단 내 볼드 남발을 지양하고, 담백한 서술형 문장을 씁니다.

## ✨ 무엇을 하나요?

1. **이륙 전 체크리스트** — "누가 쓰나요?", "파일을 올리나요?", "비밀 키가 들어가나요?" 같은
   쉬운 질문을 한 화면에 하나씩 던집니다. 모르면 **"잘 모르겠어요"**를 눌러 이유와 함께 추천을 받습니다.
2. **가드레일 프롬프트 생성** — 답변을 상태 관리 / 멀티 테넌시 / 파일 I/O / 비밀 관리 / 아키텍처
   규칙으로 매핑해, Cursor·Claude·ChatGPT에 **가장 먼저** 붙여넣을 마스터 프롬프트를 만들어 줍니다.
3. **복사 한 번** — 완성된 프롬프트를 클립보드로 복사해 바로 사용합니다.

이 프롬프트는 단순 요구사항 명세서가 아니라, LLM의 페르소나에 소프트웨어 공학 매뉴얼을 주입하는
**'제약의 감옥(Constraint Prison)'** 입니다.

## 🚀 실행 & 배포

### 웹사이트 (로컬 미리보기)
정적 파일이라 서버만 있으면 됩니다.
```bash
python3 -m http.server 8000
# http://localhost:8000/ (랜딩) · /app.html (생성기) · /guides/ (가이드)
```
#### 지금 라이브 (GitHub Pages · 자동)
기본 브랜치에 push 하면 `.github/workflows/deploy-pages.yml`이 자동으로 배포합니다.
- URL: `https://baebae6ae.github.io/nocalhostmore/`
- 내부 링크가 모두 상대경로라 서브패스에서도 정상 동작합니다.

#### "정식 서비스"로 승격 (Vercel + 커스텀 도메인, 추천)
가장 프로처럼 보이는 방법은 **Vercel + 내 도메인**입니다(서버리스 함수로 나중에 결제도 가능).
1. [vercel.com](https://vercel.com) 로그인 → **Add New → Project** → 이 저장소 Import (빌드 설정 없음, Framework: Other)
   - 저장소에 `vercel.json`(clean URLs)이 포함돼 있어 별도 빌드 설정이 필요 없습니다. 기본 브랜치가 자동으로 프로덕션이 됩니다.
2. 배포되면 `xxx.vercel.app` 즉시 생성. **Settings → Domains**에서 구입한 도메인 연결(HTTPS 자동)
3. `robots.txt`·`sitemap.xml`의 도메인을 실제 값으로 교체

#### Google AdSense 신청 절차
1. 배포된 사이트(가능하면 커스텀 도메인)로 [google.com/adsense](https://www.google.com/adsense) 가입 → 사이트 추가
2. 발급된 **인증 코드(`ca-pub-...`)** 를 `js/ads.js`의 `ADSENSE_CLIENT`에 넣고 커밋·배포
   → 랜딩·가이드 11개 페이지 모두 `js/ads-init.js`로 광고 슬롯이 연결돼 있어 자동으로 광고가 뜬다.
   (그 전까지는 광고 슬롯이 완전히 숨겨져 있어 "미완성" 인상을 주지 않는다 — `?adsdebug=1`로 레이아웃만 미리 확인 가능)
3. 승인 후 `ads.txt`의 `pub-XXXXXXXXXXXXXXXX`를 실제 게시자 ID로 교체(필수 — 없으면 수익 제한)
4. 심사에는 **개인정보처리방침**(`privacy.html`)·**이용약관**(`terms.html`)·**충분한 원본 콘텐츠**(`guides/` 10편, 800자 이상 심층 글)가
   이미 준비돼 있습니다. 얇은 도구 페이지 하나만으로는 승인이 어려우니, 가이드를 계속 늘리는 것을 권장합니다.

> 팁: 임시 배포 주소(`xxx-hash.vercel.app`)가 아니라 **고정 대표 주소**(프로젝트의 `Visit` 링크 또는 커스텀 도메인)로
> 신청하세요. 나중에 도메인을 바꾸면 새 사이트로 다시 심사를 받아야 합니다.

### 크롬 확장 (개발자 모드)
1. `chrome://extensions` → **개발자 모드** 켜기
2. **압축해제된 확장 프로그램을 로드** → 이 폴더 선택
3. 툴바 🚀 아이콘 클릭

> 아이콘 재생성: `npm run icons`

## 🧭 설계 철학: 초보는 "언어"를 모른다

초보 바이브 코더에게 "파이썬 쓸래, 자바스크립트 쓸래?"라고 물으면 아무 의미가 없습니다.
그래서 Nocalhostmore는 **언어·프레임워크를 절대 묻지 않습니다.** 대신 *의도*만 일상 언어로
묻고(배포하나? / 여럿이 쓰나? / 저장이 필요한가?), **스택과 구조는 시스템이 자동 결정**합니다.

또한 질문·답변 선택으로 **모순된 구성이 만들어지지 않도록** 분기를 설계했습니다.
서로 얽히는 축(다중 접속·데이터 격리·로그인·영속성)을 **하나의 질문으로 묶고**, 종속되는
사실은 묻지 않고 유도합니다. 그래서 "각자 내 데이터를 본다"를 고르면 → 로그인·DB·격리가
한 번에 확정되고, "저장 필요 없음" 같은 모순 선택 자체가 불가능해집니다.

## 🗺️ 질문 흐름 & 유도되는 규칙

```
1. 무엇을 만드나요? (자유 입력)               → 기능 명세서
2. 어떻게 쓸 건가요?
   ├─ 나 혼자(로컬)  ─────────────────────────→ 3. 파일? → (저장?) → 외부연결?
   └─ 인터넷에 배포  → 2-1. 사람들이 어떻게?
          ├─ 로그인 없는 도구   → 로그인X · 저장X (대부분 무료)
          ├─ 각자 내 데이터     → 로그인O · DB저장 · 사용자격리  ⚠️서버비용
          └─ 다같이 공용        → 공유상태(DB/Redis) · 경쟁상태 방지  ⚠️서버비용
7. 어떤 AI로 코딩하나요?  (출력 프로토콜을 가르는 분기)
   ├─ 채팅형(ChatGPT·Claude·Gemini) → 단계별 빌드 프로토콜(잘림 방지)
   └─ 코딩 에이전트(Cursor·Claude Code·Codex·Cline) → 파일 직접 생성·실행·검증
```

> **왜 "AI 도구"를 묻나?** 프로덕션급 프롬프트는 결과물이 커서, 채팅창에 그대로 넣으면
> 출력 길이 제한에 걸려 코드가 잘립니다. 품질을 줄이는 대신 **전달 방식**을 도구에 맞춰
> 분기합니다. 채팅형에는 "1단계 설계 → '다음' → 파일 1~2개씩 + 진행 체크리스트, 절대
> 중간에서 자르지 말 것" 프로토콜을, 에이전트형에는 "파일을 직접 생성하고 실행·테스트로
> 검증하며 TODO로 진행" 프로토콜을 주입해 **서로 다른 프롬프트**를 만듭니다.

각 선택지는 `js/promptBuilder.js`에서 아래 규칙으로 번역됩니다.

| 유도되는 사실 | 조건 | 주입되는 프로덕션 규칙 |
|---|---|---|
| **스택 자동 결정** | 서버가 필요 없음(순수 UI·무료 도구) | HTML/CSS/JS 프론트엔드, 정적 호스팅(무료), 비밀키 금지, XSS 방지 |
| | 서버 필요(AI·파일·저장·로그인·비밀키) | Python + Streamlit(화면+서버 통합) |
| **데이터 격리** | 여러 명이 각자 데이터 | `st.session_state` 강제, 전역 변수에 사용자 데이터 저장 금지 |
| **공유 상태** | 다같이 보는 공용 | DB/Redis 동기화, 트랜잭션/락으로 경쟁 상태 방지 |
| **로그인** | "내 데이터"를 봄 | 비밀번호 해싱(bcrypt), 소유자 확인 후 접근(남의 데이터 차단) |
| **파일(일회성)** | 처리 후 삭제 | UUID 파일명, `try/finally`에서 강제 삭제, 확장자·크기 검증 |
| **파일(영구)** | 계속 보관 | S3 등 오브젝트 스토리지, 사용자 ID 폴더 격리, path traversal 차단 |
| **DB 저장** | 배포+개인/공용 데이터 | SQLAlchemy ORM, raw SQL 금지, 개발(SQLite)/운영(PostgreSQL) 분리 |
| **로컬 저장** | 로컬 전용+저장 | 로컬 SQLite / `localStorage`(무료) |
| **비밀 키** | AI·외부 서비스 연결 | `st.secrets` 또는 `.env`+dotenv, `.gitignore` 등록, `.env.example` 제공 |
| **비용 안내** | 배포+DB/저장공간 필요 | 결과에 "서버·DB 유료 가능성" 명시 |

여기에 공통 안티패턴 금지(빈 예외 처리, 입력 미검증 등)와, 아이디어에 AI가 언급되면
**외부 API 비용 보호**(타임아웃·재시도·호출 상한) 규칙이 자동으로 추가됩니다.

## 💰 수익화 구조

순수 "프롬프트 생성기"는 그 자체로는 수익화가 약합니다(1회성 유틸리티). 그래서 **콘텐츠 허브 +
프리미엄 하이브리드**로 설계했습니다.

- **무료(미끼)**: 마스터 프롬프트 생성 + 히스토리 — 사용자를 불러오는 핵심 가치
- **콘텐츠(SEO·광고 지면)**: `guides/`의 실전 문서가 검색 유입과 AdSense 노출을 만든다.
  얇은 도구 페이지 대신 **글**이 광고를 싣는다. (`js/ads.js`의 `ADSENSE_CLIENT`만 채우면 활성화)
- **Pro(유료 훅)**: **스타터 레포 zip 다운로드** — 답변에 맞춘 실행 가능한 프로젝트 뼈대(`repoBuilder.js`)를
  통째로 내려받는다. 사람들은 생성기가 아니라 *아낀 시간*에 돈을 낸다. 결제(Stripe·Gumroad)는
  `js/site.js`의 페이월에서 연결하면 되고, 지금은 베타 무료로 열려 있다.
- **어필리에이트(선택)**: 결과가 추천하는 인프라(Vercel·Render·Supabase 등)에 제휴 링크를 붙일 수 있다.
