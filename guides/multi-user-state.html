여러 명이 쓰면 왜 데이터가 섞일까?

약 5분 · 상태 격리를 처음 배우는 사람을 위한 글

분명 잘 되던 앱인데, 친구에게 링크를 보내 같이 쓰기 시작하니 갑자기 친구가 입력한 내용이 내 화면에 나타납니다. 마치 남의 일기장이 내 것과 섞인 느낌이죠. 이건 해킹이 아니라, 상태(state)를 어디에 뒀느냐의 문제입니다.

냉장고 비유로 이해하기

프로그램이 값을 기억하는 방식을 냉장고에 비유해봅시다.

  • 전역 변수 = 공용 냉장고. 사무실 탕비실의 큰 냉장고 하나를 모두가 같이 씁니다. 내가 넣은 우유를 옆 사람이 꺼내 마실 수 있죠. 서버의 전역 변수도 똑같습니다. 모든 접속자가 같은 한 칸을 공유합니다.
  • 세션 = 개인 사물함. 사람마다 열쇠가 다른 사물함을 하나씩 받습니다. 내 물건은 내 사물함에만 있고, 남은 볼 수 없어요. "각자 자기 데이터만 본다"는 이렇게 만들어야 합니다.

로컬에서 나 혼자 쓸 땐 공용 냉장고라도 아무 문제가 없습니다. 사용자가 나 하나뿐이니까요. 그런데 여러 명이 접속하는 순간, 공용 냉장고(전역 변수)는 즉시 데이터가 섞이는 원인이 됩니다.

Streamlit에서의 실수와 해법

초보가 가장 많이 쓰는 Streamlit을 예로 들어보죠. 아래처럼 모듈 전역에 값을 두면 안 됩니다. 

# ❌ 나쁜 예 — 모든 접속자가 이 하나의 리스트를 공유한다
items = []

def add(x):
    items.append(x)   # A가 넣은 걸 B도 보게 된다

대신 st.session_state에 담으면, Streamlit이 접속자마다 별도의 사물함을 내어줍니다.

# ✅ 좋은 예 — 사용자(세션)별로 격리된다
import streamlit as st

if "items" not in st.session_state:
    st.session_state.items = []

def add(x):
    st.session_state.items.append(x)

규칙은 단순합니다. “이 값이 사람마다 달라야 하나?” 라고 스스로 물어보세요. 그렇다면 전역 변수가 아니라 세션에 두어야 합니다.

그럼 "다 같이 보는" 데이터는?

반대로 게시판·공지·팀 대시보드처럼 모두가 같은 내용을 함께 봐야 하는 데이터도 있습니다. 이건 세션(개인 사물함)에 두면 안 됩니다 — 각자 자기 것만 보게 되니까요. 이런 공유 데이터는 데이터베이스에 저장해서, 모든 사용자가 같은 원본을 읽고 쓰게 해야 합니다. 서버 메모리에 두면 서버가 여러 대로 늘어나는 순간 또 깨집니다.

정리: 사람마다 다른 값 → 세션. 모두가 공유하는 값 → 데이터베이스. 절대 전역 변수에 사용자 데이터를 담지 마세요.

로그인이 필요해지는 지점

"각자 자기 데이터를 내일 다시 봐야 한다"면, 세션만으로는 부족합니다. 세션은 브라우저를 닫으면 사라지니까요. 이때부터는 로그인으로 사용자를 식별하고, 데이터마다 소유자(user_id)를 붙여 본인 것만 조회하도록 서버에서 확인해야 합니다.

이 판단, 질문 몇 개로 대신 해드려요
