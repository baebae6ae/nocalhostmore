"로컬에선 됐는데 배포하니 터진다"의 진짜 이유들. 어려운 CS 용어 없이, 초보의 언어로 풀어드립니다.

기초 · 배포

로컬에선 되던 앱이 배포하면 터지는 5가지 이유

전역 변수, 사라지는 파일, 새어나가는 키… 바이브 코딩이 프로덕션에서 무너지는 전형적 패턴.
상태 관리

여러 명이 쓰면 왜 데이터가 섞일까? (상태 격리)

전역 변수와 세션의 차이를 냉장고 비유로. Streamlit session_state가 필요한 이유.
보안

API 키를 GitHub에 올려 요금 폭탄 맞지 않는 법

하드코딩이 위험한 이유와 .env·st.secrets·.gitignore 실전 세팅.
스택 선택

프론트엔드만으로 충분할 때 vs 백엔드가 필요할 때

언어를 몰라도 되는 이유. "서버가 필요한가?"가 스택을 자동으로 정해줍니다.
데이터 · 비용

데이터 저장이 필요할까? 서버·DB가 돈이 되는 순간

새로고침하면 사라져도 되는지로 갈리는 영속성. DB가 필요한 순간과 무료로 시작하는 법.
파일 · 안정성

파일 업로드, 이렇게 하면 서버가 터진다

UUID 파일명, 용량·확장자 검증, finally 강제 삭제, 사용자별 격리까지.
AI 활용

AI에게 큰 프로젝트를 잘림 없이 받는 법

코드가 중간에 잘리는 이유와 단계별로 나눠 받는 법. 채팅형 vs 에이전트형.
