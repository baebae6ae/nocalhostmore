problem

대부분 문제는 설계에서 시작된다

기능 구현에만 매달리다 보면 여러 명이 접속했을 때 데이터가 섞이고, API 키가 새어나가고, 배포하면 파일이 사라지는 일이 생깁니다. 나중에 코드를 다시 짜는 대신, 처음에 몇 가지만 정해두면 됩니다.

state

상태·동시 접속

여러 명이 써도 데이터가 섞이지 않도록 세션 격리·공유 상태 규칙을 넣습니다.

secrets

비밀 키 관리

API 키 하드코딩을 막고 .env·st.secrets 사용을 강제합니다.

storage

데이터·파일

일회성/영구 저장, 파일명 처리, DB 뼈대까지 상황에 맞게 규칙화합니다.

stack

스택 자동 결정

언어를 고를 필요 없습니다. 의도만 답하면 프론트엔드/파이썬 중 알맞은 쪽을 정합니다.

workflow

3단계

설정 없이, 답하고 복사하면 됩니다.

질문에 답한다

"누가 쓰나요", "파일을 올리나요" 같은 질문에 클릭으로 답합니다. 모르면 추천을 받을 수 있습니다.

프롬프트를 만든다

답변이 상태·보안·아키텍처 규칙으로 바뀌어, 잘리지 않고 전달되는 프롬프트가 나옵니다.

AI에게 붙여넣는다

ChatGPT·Claude·Cursor 등에 가장 먼저 붙여넣으면, 그 규칙 위에서 코딩이 시작됩니다.
